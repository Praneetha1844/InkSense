# Security Policy

This repository contains a notebook only. It has no service and handles no secrets or personal data.

Trained model files (`*.h5`, `*.keras`) are ignored by git. If you load a model file from an untrusted source, remember that saved Keras models can execute code when loaded. If you find another problem, please report it privately through the repository's **Security** tab (GitHub security advisories) rather than a public issue.

Supported version: the latest commit on `main`.
